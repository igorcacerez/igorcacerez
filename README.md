Sou desenvolvedor de software e docente de Desenvolvimento de Sistemas no **SENAI**. Minha experiência passa por aplicações web e mobile, APIs, integrações, infraestrutura e inteligência artificial aplicada.

Gosto de acompanhar o caminho completo: entender o problema, desenhar a experiência, construir a solução e colocá-la em produção. Tenho experiência em liderança técnica e levo para a sala de aula o que aprendo construindo produtos.

## IA que participa do trabalho

Meu interesse está em transformar modelos em ferramentas úteis: integrar contexto, conectar APIs, definir o fluxo de execução e avaliar o resultado.

- **Agentes e automações:** conectar atendimento, agenda, mensagens e processos de negócio.
- **IA dentro de produtos:** criar funcionalidades com uma experiência simples para quem usa.
- **Execução local:** explorar LLMs e geração de áudio com ferramentas abertas.
- **Ferramentas para desenvolvimento:** criar skills e fluxos reutilizáveis para tarefas recorrentes.

Estou explorando a **orquestração de agentes para desenvolvimento de software**, combinando diferentes papéis, ferramentas e modelos conforme a necessidade de cada tarefa.
